Reconciling stock counts across several warehouses when the totals disagree with the recorded movements
=========================================================================================================

This page has a deliberately long title and no sections, so it has nothing to list
under "On this page".

When a physical count disagrees with the recorded stock, record an adjustment rather
than editing the stock level directly. The adjustment keeps the history honest, and it
shows up in the movements report with the reason you give. A longer paragraph lets you
judge line length on a wide screen: it should wrap well before it reaches the far edge
of the content column, so that the eye can find the start of the next line without
effort. If this line runs the full width of a large monitor, the measure is too wide.
