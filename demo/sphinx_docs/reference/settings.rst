Settings
========

Administrators change these under **Settings → Inventory**.

``MAX_IMPORT_ROWS``
   The most rows one import may contain. Default ``5000``.

``DEFAULT_REORDER_POINT``
   Reorder point given to new products when none is set. Default empty.

``CURRENCY``
   ISO 4217 code for prices. Default ``EUR``. [#currency]_

.. [#currency] Changing the currency does not convert existing prices.
