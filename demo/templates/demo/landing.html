Quick start Explore the demo We are not reinventing the wheel. extends Django's own views and brings in the packages most projects already rely on, so most of it is familiar on day one. MVPListView is a ListView. The methods you would override are still there and still do what they did. An established package with its own documentation, not a syntax invented here. Sidebar, navbar and themes are set in one place, the way Django projects already work. The stylesheet ships prebuilt, so there is no front-end toolchain to learn before the first page.
