The arguments

Every page title takes the same arguments. Each one is set on the view, by attribute or by method, or replaced by itself from a template block.

ArgumentView attributeMethodBlock
Eyebrowpage_eyebrowget_page_eyebrow()page.eyebrow
Titlepage_titleget_page_title()page.heading
Leadpage_leadget_page_lead()page.lead
Actionspage_actionsget_page_actions()page.actions
Infopage_info, page_info_actionsget_page_info()page.info

The layouts

default
Eyebrow, heading and lead in one column, with the actions beside them on a wide screen and under them on a narrow one. Page, form, detail and delete pages draw it unless told otherwise.
inline
The actions stay on the heading's own row at every width, and the lead runs the full width below. List pages draw it.
centred
Everything centred in one column, the actions under the lead. For overview pages and pages that open a section.
compact
One row: eyebrow, heading, info and, where there is room, the lead, with the actions at its end. Table pages draw it inside their toolbar.

Choosing one

For the whole site, or for each page type, in the settings:

MVP_CONFIG = {
    "page_title": {"layout": "centred"},
}

MVP_CONFIG = {
    "page_title": {"layout": {"page": "centred", "list": "inline"}},
}

For one view, on the view:

class OverviewView(MVPTemplateView):
    page_title_layout = "centred"

A layout of the project's own is a Cotton component, named the same way: "page_title": {"layout": "myapp.page_title"} draws templates/cotton/myapp/page_title.html, which receives the eyebrow, heading, lead, info and actions slots.
